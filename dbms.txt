EXPERIMENT 1: PRACTICE BASIC SQL QUERIES
------------------------------------------------------------------------------------------------
AIM: Practice basic SQL queries.
TOOLS: w3schools SQL editor (MySQL syntax).
TABLES: Customers(CustomerID, CustomerName, ContactName, Address, City, PostalCode, Country), 91 rows;
        Products(ProductID, ProductName, SupplierID, CategoryID, Unit, Price), 77 rows.

1.1  Display the records from the table.
mysql> SELECT * FROM Customers;
Result: All 91 customers, all 7 columns.

1.2  Find customer details of Mexico citizens.
mysql> SELECT * FROM Customers WHERE Country = 'Mexico';
Result: Only the rows whose Country is Mexico.

1.3  Update a record of your choice.
mysql> UPDATE Customers SET ContactName = 'Juan' WHERE Country = 'Mexico';
Result: Every Mexican customer's ContactName becomes Juan (MySQL reports how many rows changed). Without WHERE, every row would change.

1.4  List customers from Spain whose names start with G.
mysql> SELECT * FROM Customers WHERE Country = 'Spain' AND CustomerName LIKE 'G%';
Result: Both conditions must hold. 'G%' = starts with G.

1.5  Find customers who are NOT from Spain.
mysql> SELECT * FROM Customers WHERE NOT Country = 'Spain';
Result: Same as WHERE Country <> 'Spain'.

1.6  Find the minimum Price of products.
mysql> SELECT MIN(Price) FROM Products;
Result: Output: 2.5 (Geitost).

1.7  Find the maximum Price of products.
mysql> SELECT MAX(Price) FROM Products;
Result: Output: 263.5 (Cote de Blaye).

1.8  Display the total number of records.
mysql> SELECT COUNT(*) FROM Customers;
Result: Output: 91.

1.9  Find the number of customers from each country.
mysql> SELECT COUNT(CustomerID), Country FROM Customers GROUP BY Country;
Result: One row per country with its customer count.

EXPERIMENT 2: PRACTICE AND, OR, NOT, WILDCARDS AND ORDER BY
------------------------------------------------------------------------------------------------
AIM: Practice AND, OR, NOT, wildcards (LIKE with % and _) and ORDER BY.
TOOLS: w3schools SQL editor (MySQL syntax). TABLE: Customers.
Wildcards: % = any number of characters (even none), _ = exactly one character.

2.1  Retrieve all customers from Germany OR France.
mysql> SELECT CustomerName FROM Customers WHERE Country = 'Germany' OR Country = 'France';

2.2  Find customers from the USA with City 'New York'.
mysql> SELECT CustomerName FROM Customers WHERE Country = 'USA' AND City = 'New York';
NOTE: The w3schools table has no customer in New York, so this gives an empty set. The query
      itself is right.

2.3  Customers NOT from the UK with CustomerID greater than 50.
mysql> SELECT CustomerName FROM Customers WHERE NOT Country = 'UK' AND CustomerID > 50;
NOTE: NOT applies only to Country = 'UK' (NOT binds tighter than AND).

2.4  Customers from Canada OR Mexico whose ContactName starts with 'A'.
mysql> SELECT CustomerName FROM Customers WHERE (Country = 'Canada' OR Country = 'Mexico') AND ContactName LIKE 'A%';
NOTE: The file wrote this WITHOUT brackets. AND runs before OR, so the file's version returns
      ALL Canadian customers plus Mexicans whose contact starts with A. The brackets give the
      intended meaning. Same as: WHERE Country IN ('Canada','Mexico') AND ContactName LIKE
      'A%'.

2.5  Customers NOT from Spain AND NOT from Italy.
mysql> SELECT CustomerName FROM Customers WHERE NOT Country = 'Spain' AND NOT Country = 'Italy';
NOTE: Same as WHERE Country NOT IN ('Spain','Italy').

2.6  CustomerName starts with 'A'.
mysql> SELECT CustomerName FROM Customers WHERE CustomerName LIKE 'A%';

2.7  CustomerName ends with 's'.
mysql> SELECT CustomerName FROM Customers WHERE CustomerName LIKE '%s';

2.8  City contains 'on'.
mysql> SELECT CustomerName FROM Customers WHERE City LIKE '%on%';

2.9  ContactName has 'r' as the second letter.
mysql> SELECT CustomerName FROM Customers WHERE ContactName LIKE '_r%';

2.10  CustomerName starts with 'B' and is at least 3 characters long.
mysql> SELECT CustomerName FROM Customers WHERE CustomerName LIKE 'B__%';
NOTE: B + two underscores + %: at least 3 characters.

2.11  Country starts with 'G' and ends with 'y'.
mysql> SELECT CustomerName FROM Customers WHERE Country LIKE 'G%y';

2.12  Address contains 'Str.' and City starts with 'B'.
mysql> SELECT CustomerName FROM Customers WHERE Address LIKE '%Str.%' AND City LIKE 'B%';
NOTE: The file used '%Str%' (without the dot), which also matches e.g. 'Strasse'.

2.13  CustomerName starts with 'M' or 'A'.
mysql> SELECT CustomerName FROM Customers WHERE CustomerName LIKE 'M%' OR CustomerName LIKE 'A%';

2.14  Names starting with 'A' from Germany, sorted by CustomerName.
mysql> SELECT CustomerName FROM Customers WHERE CustomerName LIKE 'A%' AND Country = 'Germany' ORDER BY CustomerName;

2.15  ContactName contains 'an', ordered by Country descending.
mysql> SELECT CustomerName FROM Customers WHERE ContactName LIKE '%an%' ORDER BY Country DESC;

2.16  Customers from Mexico or Brazil, sorted by City then CustomerName.
mysql> SELECT CustomerName FROM Customers WHERE Country = 'Mexico' OR Country = 'Brazil' ORDER BY City, CustomerName;

2.17  CustomerName NOT starting with 'B', sorted by Country then City.
mysql> SELECT CustomerName FROM Customers WHERE CustomerName NOT LIKE 'B%' ORDER BY Country, City;
NOTE: The file wrote WHERE NOT CustomerName LIKE 'B%', which is the same.

2.18  PostalCode with '1' as the second character, ordered by PostalCode.
mysql> SELECT CustomerName FROM Customers WHERE PostalCode LIKE '_1%' ORDER BY PostalCode;
NOTE: Strings: the file uses double quotes ("Germany"). MySQL accepts them by default, but
      single quotes ('Germany') are standard SQL and also work in Oracle. Use single quotes in
      the exam.

EXPERIMENT 3: PRACTICE DDL COMMANDS AND CONSTRAINTS
------------------------------------------------------------------------------------------------
AIM: Practice DDL commands (CREATE, ALTER, DROP) and constraints (PRIMARY KEY, NOT NULL, UNIQUE, CHECK,
FOREIGN KEY, DEFAULT).  TOOLS: MySQL.
NOTE: MySQL 5.1 (the lab's version) uses the MyISAM engine by default, which ignores FOREIGN
      KEY constraints. Add ENGINE=InnoDB to every CREATE TABLE that has or is referenced by a
      foreign key. MySQL before 8.0.16 also accepts CHECK but does not enforce it.

3.1  Create a table Student: StudentID (Primary Key), Name (Not Null), Email (Unique), Age (Check Age > 0).
mysql> CREATE TABLE Student (
    ->   StudentID INT PRIMARY KEY,
    ->   Name VARCHAR(50) NOT NULL,
    ->   Email VARCHAR(50) UNIQUE,
    ->   Age INT CHECK (Age > 0)
    -> ) ENGINE=InnoDB;
Query OK, 0 rows affected (0.01 sec)

mysql> DESC Student;
+-----------+-------------+------+-----+---------+-------+
| Field     | Type        | Null | Key | Default | Extra |
+-----------+-------------+------+-----+---------+-------+
| StudentID | int(11)     | NO   | PRI | NULL    |       |
| Name      | varchar(50) | NO   |     | NULL    |       |
| Email     | varchar(50) | YES  | UNI | NULL    |       |
| Age       | int(11)     | YES  |     | NULL    |       |
+-----------+-------------+------+-----+---------+-------+
4 rows in set (0.00 sec)

3.2  Create a table Course: CourseID (Primary Key), CourseName, Credits (Check between 1 and 6).
mysql> CREATE TABLE Course (

3.3  Create a table Department: DeptID (Primary Key), DeptName (Unique, Not Null).
mysql> CREATE TABLE Department (

Query OK, 0 rows affected (0.01 sec)

+----------+-------------+------+-----+---------+-------+

3.4  Create a table Employee with a foreign key referencing Department: EmpID (Primary Key), EmpName, DeptID (Foreign Key).
mysql> CREATE TABLE Employee (
    ->   EmpID INT PRIMARY KEY,
    ->   EmpName VARCHAR(50),
    ->   DeptID INT,
    ->   FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
    -> ) ENGINE=InnoDB;
Query OK, 0 rows affected (0.01 sec)

mysql> DESC Employee;
+---------+-------------+------+-----+---------+-------+
| Field   | Type        | Null | Key | Default | Extra |
+---------+-------------+------+-----+---------+-------+
| EmpID   | int(11)     | NO   | PRI | NULL    |       |
| EmpName | varchar(50) | YES  |     | NULL    |       |
| DeptID  | int(11)     | YES  | MUL | NULL    |       |
+---------+-------------+------+-----+---------+-------+
3 rows in set (0.00 sec)
NOTE: Write the separate FOREIGN KEY (...) REFERENCES ... clause. A column-level 'DeptID INT
      REFERENCES Department(DeptID)' is accepted by MySQL but silently creates no foreign key.
      Key 'MUL' = a non-unique index (MySQL creates one for the FK).

3.5  Create a table Enrollment to link Student and Course: composite Primary Key (StudentID, CourseID), foreign keys to Student and Course.
mysql> CREATE TABLE Enrollment (
    ->   StudentID INT,
    ->   CourseID INT,
    ->   PRIMARY KEY (StudentID, CourseID),
    ->   FOREIGN KEY (StudentID) REFERENCES Student(StudentID),
    ->   FOREIGN KEY (CourseID) REFERENCES Course(CourseID)
    -> ) ENGINE=InnoDB;
Query OK, 0 rows affected (0.01 sec)

mysql> DESC Enrollment;
+-----------+---------+------+-----+---------+-------+
| Field     | Type    | Null | Key | Default | Extra |
+-----------+---------+------+-----+---------+-------+
| StudentID | int(11) | NO   | PRI | 0       |       |
| CourseID  | int(11) | NO   | PRI | 0       |       |
+-----------+---------+------+-----+---------+-------+
2 rows in set (0.00 sec)

3.6  Add a column Gender VARCHAR(10) to Student allowing only 'Male', 'Female', 'Other'.
mysql> ALTER TABLE Student ADD Gender VARCHAR(10)
    ->   CHECK (Gender IN ('Male', 'Female', 'Other'));
Query OK, 0 rows affected (0.01 sec)
NOTE: Existing rows get Gender = NULL.

3.7  Modify the Credits column in the Course table to make it NOT NULL.
mysql> ALTER TABLE Course MODIFY Credits INT NOT NULL;
Query OK, 0 rows affected (0.01 sec)
NOTE: MODIFY re-states the whole column definition (type + constraints). If any existing row
      has Credits NULL, fix it first or the ALTER fails.

3.8  Rename the column EmpName in the Employee table to EmployeeName.
mysql> ALTER TABLE Employee CHANGE EmpName EmployeeName VARCHAR(50);
Query OK, 0 rows affected (0.01 sec)
NOTE: MySQL 5.x has no RENAME COLUMN; CHANGE old new TYPE renames and re-states the type.
      MySQL 8 also accepts: ALTER TABLE Employee RENAME COLUMN EmpName TO EmployeeName;

3.9  Drop the Age column from the Student table.
mysql> ALTER TABLE Student DROP COLUMN Age;
Query OK, 0 rows affected (0.01 sec)

3.10  Add a DEFAULT value of 'General' to the DeptName column in the Department table.
mysql> ALTER TABLE Department ALTER DeptName SET DEFAULT 'General';
Query OK, 0 rows affected (0.01 sec)
NOTE: ALTER [COLUMN] col SET DEFAULT v changes only the default; DROP DEFAULT removes it.
      Existing rows are not changed.

3.11  Testing the constraints (what MySQL 8 / InnoDB does):

LAB 12  Open-ended: take a real-world situation, (1) draw its conceptual design (ER diagram), (2) convert it to a relational database.
Example: LIBRARY
ER design (Chen notation):
  Entities:   MEMBER (member_id [key], name, phone {multivalued}, join_date)
              BOOK   (book_id [key], title, publisher, year)
              AUTHOR (author_id [key], name)
              COPY   (weak entity: copy_no [partial key], shelf)  -- identified by BOOK
  Relationships: WRITES  AUTHOR M:N BOOK
                 HAS     BOOK 1:N COPY (identifying, total participation of COPY)
                 BORROWS MEMBER M:N COPY with attributes issue_date, due_date, return_date
Relational schema (primary keys first, FK -> parent):
  member(member_id PK, name, join_date)
  member_phone(member_id FK->member, phone, PK(member_id, phone))        -- multivalued attribute
  book(book_id PK, title, publisher, year)
  author(author_id PK, name)
  writes(author_id FK->author, book_id FK->book, PK(author_id, book_id)) -- M:N becomes a table
  copy(book_id FK->book, copy_no, shelf, PK(book_id, copy_no))           -- weak entity: owner key + partial key
  borrows(member_id FK->member, book_id, copy_no, issue_date, due_date, return_date,
          PK(member_id, book_id, copy_no, issue_date), FK(book_id, copy_no)->copy)

CREATE TABLE book (book_id INT PRIMARY KEY, title VARCHAR(100) NOT NULL, publisher VARCHAR(50), year INT) ENGINE=InnoDB;
CREATE TABLE copy (book_id INT, copy_no INT, shelf VARCHAR(10), PRIMARY KEY (book_id, copy_no),
                   FOREIGN KEY (book_id) REFERENCES book(book_id) ON DELETE CASCADE) ENGINE=InnoDB;
